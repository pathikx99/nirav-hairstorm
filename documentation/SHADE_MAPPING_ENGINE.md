# Shade Mapping Engine

> Cross-manufacturer shade matching and equivalence mapping.

## Approach

The Shade Mapping Engine uses CIEDE2000 colour-difference calculations on CIE L\*a\*b\* values to find the closest shade matches across manufacturer catalogues.

## Key Features

- CIEDE2000 ΔE* calculation (via SciPy)
- Configurable matching thresholds
- Undertone-aware comparison
- Confidence scoring for matches
