# Manufacturer Data Schema

> Defines the ingestion schema for each supported manufacturer's shade catalogue.

## Supported Manufacturers

| Manufacturer  | Status      |
|---------------|-------------|
| Wella         | Planned     |
| L'Oréal       | Planned     |
| Schwarzkopf   | Planned     |
| Matrix        | Planned     |
| Goldwell      | Planned     |
| Keune         | Planned     |

## Schema Conventions

- Shade codes are stored **exactly as provided** by the manufacturer
- Manufacturer-specific metadata is stored as JSONB
- All measurements use NUMERIC with explicit precision
