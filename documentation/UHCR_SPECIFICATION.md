# UHCR Specification

> Universal Hair Colour Record (UHCR) v1

*This document defines the canonical data model and validation rules for the Universal Hair Colour Intelligence Platform.*

## Overview

The UHCR specification establishes a standardised format for representing hair colour data across manufacturers, enabling:

- Cross-manufacturer shade comparison via CIE L\*a\*b\* colour space
- Evidence-backed verification of colour records
- Safe formulation generation from verified data only

## Core Principles

1. **Preserve manufacturer original notation** — never normalise shade codes
2. **Every verified record must reference supporting evidence**
3. **Unverified data must never generate executable formulations**
4. **Missing information must remain explicitly unknown** (no imputation)
5. **All enums must match this specification exactly**
